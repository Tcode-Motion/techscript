# TechScript 2.0 Style Guide

This guide establishes the formatting rules and stylistic standards for TechScript codebase development.

## 1. Naming Conventions

- **Variables & Fields**: camelCase (e.g. `let myVariable = 10;`).
- **Functions & Methods**: snake_case (e.g. `function process_data() { }`).
- **Models & Structs**: PascalCase (e.g. `struct DatabaseConfig { }`).

## 2. Formatting

- **Indentation**: 4 spaces indent.
- **Curly Braces**: Open brace on the same line as header, closing brace on its own line.
