# techscript_ast

Abstract Syntax Tree definitions, node schemas, and evaluation Visitor traits for TechScript 2.0.

## Contents
- `Program`: The compilation unit root node.
- `Statement`: Crate enum for declarations, control flow, loops, and block statements.
- `Expression`: Crate enum for operations, accesses, calls, and literal expressions.
- `Visitor`: Trait used to traverse AST structures.
