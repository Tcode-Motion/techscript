# TechScript 2.0 Examples Guide

TechScript provides 40 fully working examples under `public-release/examples`.

## Summary of Core Examples

1. **hello_world**: Simple print hello world.
2. **variables**: Demonstrates `let` and `const` variables.
3. **loops**: `for` and `while` loop iterations.
4. **functions**: Declaring and invoking functions with args.
5. **structs**: Instantiating and indexing structural data maps.
6. **models**: Model instances and validation.
7. **closures**: First-class nested closure functions.
8. **pattern_matching**: Matching structure models.
9. **errors**: Catching runtime exceptions.
10. **async**: Async future declarations and await workflows.

## New Standard Library Module Examples

11. **io**: Console logging APIs.
12. **fs**: Reading and writing files.
13. **net**: Binding TCP sockets.
14. **http**: Accessing HTTP clients and servers.
15. **xml**: Markup tag processing.
16. **csv**: Structured tabular comma formats.
17. **yaml**: Configuration key-value indents.
18. **datetime**: Epochs and calendar strings.
19. **env**: Command-line args and env strings.
20. **process**: Spawning subprocess commands.
21. **crypto**: Simulated symmetric key cryptos.
22. **hash**: Generating MD5, SHA-1, SHA-256 hashes.
23. **random**: Selecting values and numbers.
24. **regex**: Text match replacements.
25. **path**: Directory strings processing.
26. **thread**: Native OS thread tasks execution.
27. **sync**: Locking mutex constructs.
28. **channel**: Sending and receiving queue channels.
29. **logging**: Structured system info logs.
