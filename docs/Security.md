# Security Policy

This document describes how vulnerability reports are handled for the TechScript repository.

---

## 🛡️ Supported Versions
Only the latest major version receives security updates.

| Version | Status |
|:---:|:---|
| **v2.0.x** | ✅ Supported |
| **v1.0.x** | ❌ Deprecated |
| **< v1.0.0** | ❌ Deprecated |

---

## 🛑 Reporting a Vulnerability
If you identify a security issue, do **not** file a public GitHub issue. Send a report to our security team instead:

1. Email: **security@techscript.is-a.dev**
2. Include:
   * A detailed description of the vulnerability.
   * Proof-of-concept (PoC) scripts to reproduce the issue.
   * Potential impact details.

We will review your submission and respond within 48 hours to coordinate a security release.
