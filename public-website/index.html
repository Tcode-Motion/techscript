Install

VS Code extension

Search for TechScript in Extensions, or use the id below.

tanmoy.techscript

Includes syntax highlighting, snippets, icons, and LSP diagnostics/completions.

PyPI

Install the Python package (includes a CLI entrypoint).

pip install techscript

Then run: tech --help

Rust binaries

Download from GitHub Releases if you prefer native executables.

tech Releases

This site is static; link your repo/releases when publishing.

Examples

CLI

tech run examples/hello.txs
tech fmt examples/web_app.txs
tech lint examples/web_app.txs
tech test examples/

Debug flags

tech run --ast examples/hello.txs
tech run --bytecode examples/web_app.txs
tech run --trace examples/api_server.txs

For headless web/server tests: set TECHSCRIPT_HEADLESS=1.

Modules

use web
Generate and serve HTML/CSS/JS from TechScript.
use gui
Simple desktop UI building blocks.
use three_d
Create scenes and render shapes.
use anime
Generate anime.js style animations.
use api
Run a tiny HTTP server and return JSON/text/html.

Publish

Marketplace

See vscode-extension/PUBLISHING_GUIDE.md in this repo.

cd vscode-extension
npx @vscode/vsce package
npx @vscode/vsce publish -p <PAT>

PyPI

Build + upload with:

python -m build
python -m twine check dist/*
python -m twine upload dist/*
