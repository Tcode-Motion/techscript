Welcome to the TechScript community! We provide multiple channels for assistance, bug reporting, feature proposals, and architectural discussions.

- **GitHub Discussions**: [Tcode-Motion/techscript/discussions](https://github.com/Tcode-Motion/techscript/discussions)

---

## 🐛 Reporting Bugs

If you find a bug in the compiler, runtime, WebForge, standard library, or CLI:

1. Search existing issues at [GitHub Issues](https://github.com/Tcode-Motion/techscript/issues) to see if it has already been reported.
2. If not, open a new issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
3. Include:
   - Operating system and architecture (`uname -a` or Windows build version).
   - TechScript version (`techscript version`).
   - A minimal reproducible example (`.txs` file).
   - Expected vs actual behavior.
   - Any compiler error codes or backtraces.

---

## 💡 Requesting Features

To propose enhancements to the TechScript language grammar, standard library, WebForge components, or tooling:
1. Open a discussion on [GitHub Discussions: Ideas](https://github.com/Tcode-Motion/techscript/discussions/categories/ideas) to collect early feedback.
2. Once the syntax and design are clear, file a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).

---

## 🔒 Security Inquiries

For sensitive vulnerability reports, please do **NOT** open public issues. Follow the instructions in [SECURITY.md](SECURITY.md) to disclose vulnerabilities responsibly.
