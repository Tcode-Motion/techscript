Introduction & Getting Started

Welcome to the TechScript 2.0 developer guide. TechScript is a general-purpose, strongly typed programming language built for speed, safety, and modern developer ergonomics. It compiles down to native binary code via an optimized LLVM backend or can be executed dynamically inside a lightweight stack virtual machine.

🚀 Core Strengths:

  • High-performance LLVM compilation to native x86_64 binaries.
  • Resilient, syntax-error-recovering parsing.
  • Built-in cooperatively scheduled async event loop runtime.
  • Integrated Package Manager & LSP daemon out-of-the-box.

Installation Guide

Get TechScript 2.0 running on your system in minutes.

Windows Installer

Download the installer executable TechScript_Setup.exe. Run the installer to configure binaries under Program Files\TechScript\bin and automatically append it to your environment PATH variable.

Verify Installation

tsc --version
tsc doctor

Language Syntax

TechScript uses clean syntax inspired by modern structural languages.

Quick Hello World

build main() {
    say "Hello, World!";
}

The compiler uses the say keyword for formatted printing to stdout. Semicolons are optional.

Variables & Constants

Variables are declared using the make keyword, while constants are declared using const.

Mutable Variables

make age = 30;
age = 31; // reassignment allowed

Immutable Constants

const gravity = 9.81;
// gravity = 10.0; -- Compile-time Error!

Functions & Closures

Functions are declared with the build keyword and are first-class values.

Standard Declaration

build multiply(a, b) {
    return a * b;
}

Anonymous Closures

build adder(x) {
    return build(y) {
        return x + y;
    };
}

Structs & Enums

Organize data cleanly using structs and enums.

Structs

struct Point {
    x,
    y
}

make pt = new Point { x: 1, y: 2 };
say pt.x;

Enums

enum Option {
    Some(val),
    None
}

Traits & Interfaces

Traits allow defining shared behavior for structs and models in TechScript.

trait Printable {
    build format();
}

model User implements Printable {
    make name = "Alice";
    build format() {
        return "User: " + self.name;
    }
}

Collections & Lists

Lists and Maps are core primitives inside the TechScript runtime.

make list = [1, 2, 3];
list.push(4);
say list[0]; // prints 1

make map = { "a": 1, "b": 2 };
say map["a"]; // prints 1

Loops & Control Flow

Standard loop structures are simple and direct.

make i = 0;
while i < 5 {
    say i;
    i = i + 1;
}

Pattern Matching

Destructure variables, struct values, and enum fields using match blocks.

make opt = Option::Some(42);
match opt {
    Option::Some(val) => { say val; },
    Option::None => { say "Empty"; }
}

Modules & Exports

Manage code scopes cleanly across files.

Exporting Symbols

export const version = "2.0";
export build greet(name) {
    return "Hello " + name;
}

Importing

import { greet, version } from "./helper.txs";

Packages & Workspaces

TechScript projects are governed by tech.toml packages. Multi-crate setups can be managed via workspaces.

[workspace]
members = [
    "packages/core",
    "packages/app"
]

Error Safety & Exceptions

Exceptions are handled natively using cooperative try/catch scopes.

attempt {
    make data = read_file("missing.txt");
} catch err {
    say "Failed to read file: " + err;
}

Generics & Types

Type parameters allow writing generic structs and functions checked by the semantic resolver.

struct Wrapper<T> {
    value: T
}

Memory Model & GC

TechScript uses a mark-and-sweep garbage collector in its VM runtime. Objects, lists, and maps are allocated on the VM heap and tracked automatically.

Compiler Architecture & Stages

The tsc compiler stages are:

  1. Lexer: Tokens extraction from raw text.
  2. Parser: Resilient AST construction.
  3. Semantic: Type checking and symbol binding.
  4. SSA IR: Lowering to Static Single Assignment forms.
  5. Optimizer: Constant folding and dead code elimination.
  6. Bytecode: Generating flat VM instructions.

SSA Bytecode Format

The compiler generates highly dense binary instructions. Subcommands like tsc dump-bytecode disassemble files into readable VM codes.

Stack Virtual Machine

The virtual machine uses a lightweight stack-based executor with dedicated stack frames, instruction pointer, and native calling interfaces.

LLVM Backend & Native Build

Compiling with the native compiler driver leverages LLVM to translate SSA IR into target machine code, producing optimized native executables.

Package Manager

Manage project manifests (tech.toml) and dependencies dynamically.

tsc install

Resolves dependency trees, fetches binaries, validates checksums, and updates tech.lock.

CLI Reference

  • tsc run <file>: Runs a script file using VM or Interpreter
  • tsc build <file>: Compiles code to native binary using LLVM
  • tsc fmt: Formats code style rules
  • tsc lint: Verifies static analysis guidelines
  • tsc repl: Starts interactive terminal environment

VS Code Integration

Install the packaged extension techscript.vsix into VS Code to enjoy full language support, syntax highlights, task definitions, and debugger integration.

LSP Daemon

The language server daemon provides auto-completion, active diagnostics, format-on-save, and rename symbols features using the Language Server Protocol.
