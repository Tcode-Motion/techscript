# techscript_errors

Diagnostic compilation results, warning and error mappings, and terminal error rendering functions for TechScript 2.0.

## Contents
- `DiagnosticLevel`: Error, Warning, and Note category indicators.
- `ErrorCode`: Unified compiler diagnostics code registry.
- `Diagnostic`: Unified error message + Span representation.
- `DiagnosticReporter`: Safe registry for collecting, sorting, and displaying compilation results.
