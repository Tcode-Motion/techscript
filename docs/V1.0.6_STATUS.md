# TechScript v1.0.6 — What Is Done

> **Print to PDF:** Open this file in VS Code or a browser → Print → Save as PDF.

**Release:** v1.0.6 · **Date:** May 2026 · **Primary runtime:** Rust (`tech` binary in `runtime/`)

---

## Summary

TechScript v1.0.6 is a **Rust-first** language. You run programs with the native `tech` command. Python under `src/techscript/` is kept only for optional parity checks, not required for daily use.

| Area | Status |
|------|--------|
| Rust VM (lexer → parser → compiler → bytecode) | Done |
| CLI (`run`, `build`, `check`, `repl`, `new`, `doctor`, `test`, `debug`, `pkg`) | Done |
| Dual syntax aliases (`class`, `try`, `loop`, `const`, …) | Done |
| Modules: `web`, `gui`, `3d`, `anime` | MVP done |
| Integration tests + smoke scripts | Done |
| VS Code extension grammar v1.0.6 | Done |
| GitHub Actions CI | Done |
| String interner / NaN boxing GC | Deferred to v1.0.7 |
| Full 3D engine (wgpu/three-d) | Deferred (2D preview MVP) |
| Installers / `.vsix` publish | Partial (scripts exist; rebuild locally) |

## Repository layout (after cleanup)

```
techscript/
├── run.bat           # Windows launcher (build / run / smoke)
├── runtime/          # Rust VM + `tech` binary (main product)
├── examples/         # Runnable .txs demos
├── runtime_examples/ # Language tutorial scripts
├── docs/             # Guides and status (this file)
├── scripts/          # setup, smoke, parity, run_example
├── vscode-extension/ # Syntax highlighting
├── assets/           # Logo and icons
├── src/techscript/   # Python reference (optional)
└── tests/            # Python pytest (optional)
```

**Removed:** `graphify-out/`, `public website/`, old installers (`build_v1.0.3.bat`, PyInstaller tree), `Makefile`, obsolete smoke tests, old `.vsix`.
