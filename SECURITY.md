# Security Policy

## Supported Versions

Only the active release version receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not report it publicly. Instead, report it privately by sending an email to `security@techscript.org`.

We will acknowledge receipt of your report within 48 hours and provide a detailed timeline for addressing the issue.
