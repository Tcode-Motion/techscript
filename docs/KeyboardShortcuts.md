# Keyboard Shortcuts — TechScript 2.0 VS Code Integration

Below are the default keyboard shortcuts and commands recommended for writing TechScript.

| Command / Action | VS Code Command ID | Default Keybinding |
| ---------------- | ------------------ | ------------------ |
| **Run File** | `techscript.run` | `Ctrl+F5` (Context: `techscript`) |
| **Debug File** | `workbench.action.debug.start` | `F5` |
| **Build Project** | `techscript.build` | `Ctrl+Shift+B` |
| **Format File** | `editor.action.formatDocument` | `Alt+Shift+F` |
| **Go To Definition** | `editor.action.goToDeclaration` | `F12` |
| **Find All References**| `editor.action.referenceSearch.trigger` | `Shift+F12` |
| **Rename Symbol** | `editor.action.rename` | `F2` |
| **Quick Fix / Actions**| `editor.action.quickFix` | `Ctrl+.` |
| **Show Outline** | `outline.focus` | `Ctrl+Shift+O` |
